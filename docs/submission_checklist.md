## 선택한 웹 도구 제출 방식

PDF의 제출 방식 **③ 실제 화면 세트와 필터·기간 변경 시나리오**를 선택했다. REPORT 부록 A에 공개판 실제 캡처 3장과 전체→2022년·ETH가격→수익 대용·예측 검증 탭 시나리오를 제공한다. 웹 앱 호스팅이 아닌 GitHub 제출이며 로컬 실행법도 제공한다. 기존 전체 앱 소스는 보존했지만 제한 원본 없이는 원래 모든 기능을 실행할 수 없다.

추가 심화는 시간순 3개월 방향 예측·단순 기준 대비 검증이다. **35개 중 0개 통과** 결과를 명시한다. 심화 분석 수행을 구매 예측 정확도 확보와 혼동하지 않는다.
