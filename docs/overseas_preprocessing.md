# 해외 CPU·SSD 주별 데이터 전처리

기준일은 2026-10-21이다. 기존 공개 자료 확보 단계에서 저장한 PriceHistory 응답을 입력으로 사용했다. 원본 HTML·JSON은 수정하지 않았다. 데이터 생성에는 네트워크 접속과 추가 패키지가 필요 없다.

## 가격의 의미

공급자의 [가격 정의](https://pricehistory.app/page/pricing-disclaimer)는 상품가와 배송비를 고려해 판매자를 선택하며, 선택된 판매자의 표시 가격을 가격 이력에 사용한다고 설명한다. 일반 `Price`는 Lightning Deal을 제외하고, 할인·쿠폰을 반영하는 `Offer Price`를 구분한다. 따라서 본 데이터의 `price`는 **Amazon.com 상품 페이지에 대응하는 판매 호가 기록**으로 정의한다. 판매 완료 금액, 미국 전체 시장 평균, 한국 구매 총비용으로 해석하지 않는다.

입력은 `History.Price[].x/y`이다. `Price`, `Main`, `PriceDays`는 최근 상태이므로 과거에 반복해서 붙이지 않는다. 두 제품의 `History.OfferPrice`에는 각각 1,227·998개의 `{x:null,y:null}` 자리표시자만 있어 가격 관측에 포함하지 않았다. 이는 유효한 가격 2,225개와 별개의 배열이다.

SSD 최근 응답은 `Main.Price=279`, `Main.Shipping=7.11`, `Main.FinalPrice=286.11`이다. 마지막 이력 가격은 279이므로, 배송비 포함 금액을 이력 가격에 임의로 더하지 않았다. 과거 시점별 배송비, 세금, 회원 조건, 판매자와 상품 상태는 이력 배열에서 확인할 수 없다. 동일 ASIN 안의 판매자·상품 상태·제품 내부 구성 변경도 통제되지 않는다. `source_timezone`은 `unknown`으로 유지했다. 날짜를 임의로 한국 시간이나 UTC로 바꾸지 않는다.

제품 식별 근거: [CPU 제품 페이지](https://pricehistory.app/p/amd-ryzen-5-3600-6-core-12-tihFavce), [SSD 제품 페이지](https://pricehistory.app/p/samsung-970-evo-plus-ssd-1tb-nvme-B1P5Osmb). 과거 배열의 마지막 갱신 표시는 각각 `2026-10-06 05:55:49`, `2026-09-26 14:51:35`다. 현재 웹 검색의 캐시 화면은 저장한 JSON보다 오래됐을 수 있어 가격 대체에 사용하지 않았다. 가격 정의 HTML은 `data/verification/2026-10-21/pricehistory/pricing_disclaimer.html`에 보존했다.

## 전처리 순서

1. 원본의 `History.Price` 각 행에 원본 행 번호와 JSON pointer를 붙인다. 날짜, 유한한 양수 가격, 미래 날짜 여부를 검사한다. 같은 timestamp가 두 번 나오면 조용히 하나를 선택하지 않고 실행을 중단한다. 현재 원본에서는 날짜·가격 형식 오류, 중복, 미래 행이 없다.
2. 주변 30일의 **다른 관측**이 5개 이상이면 그 가격의 중앙값을 구한다. 원본 가격이 이 중앙값의 0.5배 미만 또는 2배 초과이면 검토 표시를 붙인다. 같은 날 여러 관측이 생기면 서로 다른 timestamp도 비교 대상이다. 이 표시는 관측을 자동 삭제하지 않는다. 양쪽 30일을 보는 사후 감사이므로 실시간 추천이나 예측의 입력으로 사용하면 미래 정보가 들어간다.
3. `config/price_preprocessing.json`에 timestamp와 가격을 명시한 CPU 2건을 `unverified_extreme_quote`로 격리한다. 오류로 확정한 것은 아니다. 규칙에 지정한 값이 원본과 달라지거나 없어지면 실행을 중단한다. 나머지 통계적 검토 표시 행은 유지한다.
4. 원본 날짜 기준 **토요일 00:00~금요일 23:59:59**를 한 주로 묶는다. `week_end`는 실제 금요일 날짜, `week_start`는 그 6일 전이다. 해당 주 안에서 마지막으로 관측한 채택 가격을 `price_usd`로 선택한다. 평균·최저가를 대신 계산하지 않는다. 같은 날짜의 관측이 여러 개면 timestamp가 가장 늦은 것을 고른다.
5. 채택 관측이 없는 주의 가격·관측일·변화율을 공란으로 둔다. 0, 보간, 전 주 가격 이월을 사용하지 않는다. 따라서 빈 주를 삭제한 뒤 `pct_change`를 계산하면 안 된다. CSV의 공란은 결측이고 실제 변화율 0은 숫자 0이다.
6. 현재 주는 완료되지 않아 제외한다. 기준일이 금요일이어도 날짜만으로 당일 완료를 알 수 없으므로 그 직전 금요일까지만 포함한다. 원본 최신 가격은 별도로 보관하며 현재 주의 과거 관측을 만들어 넣지 않는다.
7. `weekly_2020_2022.csv`는 분석 기간 안에 **주 시작과 끝이 모두 들어오는** 주만 선택한다. 첫 주는 2020-01-04~10, 마지막 주는 2022-12-24~30이다. 첫 행의 변화율은 분석 표 안에 이전 주가 없으므로 다시 비운다. 분석 표 밖 가격을 변화율의 분모로 쓰지 않는다.

주별 선택 가격을 `P_t`라고 할 때, 현재 주와 바로 전 달력 주가 모두 유효하면 `price_change_fraction=P_t/P_(t-1)-1`, `log_return=ln(P_t/P_(t-1))`이다. 앞 주가 결측이면 그 전 유효 관측까지 건너뛰지 않는다. `quote_interval_days`는 실제 선택된 관측일 사이의 간격이다. 주차가 연속이어도 관측일 간격은 정확히 7일이 아닐 수 있다.

`log_return_unflagged`는 두 주의 **선택된 가격**에 통계적 검토 표시가 없을 때만 값을 남기는 민감도 비교용 열이다. 이번에 유지한 검토 표시 3건은 모두 주 마지막 선택 가격이 아니므로 기본 변화율과 값·개수가 같다. 이 열을 별도의 검증된 가격으로 해석하지 않는다.

## 제외·유지 내역

원가격과 이웃 가격을 담은 개별 예시 표는 공개 제외했다. CPU 2건을 원문·인근 관측 교차 확인 뒤 격리하고, 나머지 양수 급변은 검토 표시와 함께 보존했다. 격리·변화율·주별 선택 검증 코드는 유지한다.

가격 격리로 바뀐 주별 마지막 가격은 전체 기간에서 **2020-05-08 주 1개**다. 바로 다음 주의 변화율에도 분모 변경이 반영된다. `raw_last_price_usd`와 `raw_last_quote_timestamp`를 함께 제공하므로 격리 전후를 비교할 수 있다. 격리를 적용하지 않는 민감도 자료가 필요하면 설정 파일을 복사해 `quarantine`을 빈 배열로 만들고, **별도 출력 폴더**로 실행하면 된다. 원본을 직접 수정하지 않는다.

2020~2022년 표에서 제외된 채택 관측은 CPU의 기간 밖 510개, 분석 경계 주 3개와 SSD의 기간 밖 641개다. CPU 경계 관측은 2020-01-02 189.99달러, 2020-01-03 192.60달러, 2022-12-31 113.99달러다. 이 값은 전체 기간 표와 관측 감사표에 남아 있으며 가격 오류로 분류하지 않는다. 격리 2건 중 한 건은 분석 기간 안, 한 건은 밖이다. 합계는 다음처럼 원본에 맞는다.

- CPU: 1,227 = 전체 채택 1,225 + 격리 2. 채택 1,225 = 핵심 기간 712 + 기간 밖 510 + 경계 3.
- SSD: 998 = 전체 채택 998 + 격리 0. 채택 998 = 핵심 기간 357 + 기간 밖 641.

행별 세부 값은 `observations_audit.csv`의 `status`, `exclusion_reason`, `core_exclusion_reason`으로 확인한다. 격리 행만 모은 파일은 `excluded_records.csv`다. 기간 밖 행 전체를 중복 파일로 복사하지 않고 감사표에서 추적한다.

경로는 모두 `data/processed/2026-10-21/overseas/` 아래다. CSV는 Excel에서 한글을 읽을 수 있도록 UTF-8 BOM으로 저장했다. 가격은 USD, 변화율은 비율 단위다. 예를 들어 `price_change_fraction=0.05`는 5%다. 식별자·날짜는 문자열로 저장한다.

관측 감사표에는 추가로 `source_pointer`(`/History/Price/0` 등, 0부터 시작), `neighbor_count`, `neighbor_median`, `ratio_to_neighbor_median`과 사유 열이 있다. `core_exclusion_reason`은 격리 사유를 우선 기록하고, 채택 행에 한해 기간 밖·경계 주 여부를 기록한다.

## 재현과 검증

프로젝트 루트에서 Python 3.10 이상으로 실행한다. 표준 라이브러리만 사용한다.

```bash
python3 scripts/preprocess_overseas_prices.py
python3 -m unittest discover -s tests -v
```

출력 경로는 `--output-dir`로 바꿀 수 있다. 입력 원본과 설정 파일은 프로젝트 안에 두고 `--source-dir`, `--config`로 지정한다. 입력의 기존 SHA-256은 앞선 확보 감사의 `alternatives/validation.json`과도 대조한다. 테스트는 결측 주를 건너뛴 변화율 차단, 실제 변화율 0 보존, 중복·비정상 가격, 주 경계, 첫 변화율 초기화, 같은 날 관측 선택, 격리 후 같은 주 관측만 선택, 원본 해시, 2,225개 원본 행 수와 모든 주별 선택·변화율을 독립적으로 확인한다.

## 다음 분석에서 지킬 조건

주가와는 `product_id`, `week_end`를 기준으로 결합하고 주가도 동일한 토요일~금요일 범위의 마지막 거래일 수정주가로 맞춘다. 주가의 휴장과 부품 가격의 미관측을 구분한다. 가격 결측 때문에 주가를 복제하거나 부품 가격을 이월하지 않는다. 최종 상관관계의 표본 수는 두 변화율이 동시에 있는 행으로 다시 집계해야 한다.

원본 시각대가 미확인이므로 주 경계에 걸린 관측은 하루 이동 등 민감도 확인이 필요하다. 이번 파일만으로 주가의 선행·후행 관계나 인과관계를 확정하지 않는다. CPU 1개와 SSD 1개는 각 부품 시장 전체를 대표하지 않으며, 채굴 수요의 직접 검증은 별도 GPU 시계열과 사건 자료를 결합해야 한다. 단종·희소 재고로 오래된 제품 가격이 오르는 구간은 현재 제품의 가성비로 일반화하지 않는다.
