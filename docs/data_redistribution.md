# 데이터 재배포 정책 (data_redistribution)

확인일: 2026-10-24 (KST).
대상: https://github.com/highslow1536/Codyssey-M1-1
범위: 아래 주요 출처의 공식 이용조건을 확인해 공개 범위를 정한다.
한계: 웹에 공개된 이용조건만 사용했다. 계정 가입·로그인·정책 동의·수집 금지 회피·다운로드 재수집은 하지 않았다.
이 문서는 확인한 근거와 공개판의 처리 방침을 기록한다. 모든 파생물에 대한 이용 허가를 확보했다는 뜻은 아니다.
불명확한 부분은 허용 미확인으로 표기했고, 공개 열람 가능을 재배포 허용으로 추정하지 않았다.
원문 약관 대신 요약과 공식 링크를 제공한다.
연락·서면 허가 요청은 이 작업에서 하지 않았다.

## 공개 범위

포함:
- 전체 코드와 공개용으로 정리한 문서. 제한 원본의 표·가격 예시는 제거하고 제외 링크에는 data/README.md 안내를 연결한다.
- CoinMetrics Community 라이선스 조건을 준수하는 ETH 라이선스 데이터.
- 원가격을 복원하지 않는 자체 집계 CSV·설명도와 허용된 ETH 그림. 모든 자체 그래프를 무조건 포함하는 것은 아니다.
- 별도 ETH 공개 대시보드.

제외(공개본 제외, 로컬 보존):
- 원본 행 단위 가격·주가·벤치마크 표.
- 위 표를 복원할 수 있는 JSON·SVG·다운로드 ZIP.
- 제한 원가격 곡선, 현재 견적표, 원가격이 노출되는 기존 UI 캡처, 개별 정답·예측 행.
- 원래 전체 스냅샷과 화면 자료는 로컬에 보존하고, 공개본만 submission-public/ 별도 묶음으로 제공한다.

분리 원칙:
- 자체 작성 방법론, 비가역 집계 통계(관측 수·상관계수·모형 오차 등), 설명도는 연구 결과물로 분리한다.
- 이를 원본 재배포 허가나 전면적인 법적 보장처럼 표현하지 않는다.

## 기타 출처

TechSpot·네이버·에누리·퀘이사존·Wayback 등 보조 출처는 원문 데이터의 공개 재배포 허가를 별도로 확인하지 못했다. 관련 원문·행별 가격·성능 전사표는 공개 제외한다. 아카이브에 저장됐다는 이유로 원저작물의 재배포 권리가 생기지는 않는다. 사용 방법·출처 URL·비가역 요약만 남긴다.

## 코드의 검증 상수

코드의 산식·정책값·제품 사양·소량 회귀검증 상수는 코드 맥락으로 보존했다. 국내 8제품 견적의 전체 기대값 배열은 공개 테스트에서 SHA-256 일치 검사로 바꿔 원래의 정확한 검증 조건을 유지하면서 가격 표 노출을 줄였다. 공개판에 없는 원본을 읽는 검사는 별도 허가 자료 없이는 실행되지 않는다. 이 조치를 데이터 재배포의 포괄적 허가로 해석하지 않는다.
