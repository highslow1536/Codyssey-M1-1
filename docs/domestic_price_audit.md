# 국내 8제품 PC·모바일 가격 감사

2026-10-21 저장 응답을 비교한 자체 감사다. 공개판에는 비교 방법과 집계만 남기고 원가격·응답·불일치 가격쌍은 제외한다. [출처별 조건](data_redistribution.md)

## 가격 정의

상품 식별자·포장·용량·통화(KRW)를 고정하고 차트의 `minPrice`를 출처의 최저가 추이 라벨로만 해석한다. 과거 배송비·현금/카드·쿠폰·품절몰 처리·월/주 집계 정의는 확인되지 않은 항목으로 유지한다. 현재 UI의 가격 조건을 과거로 소급하지 않는다. 모바일의 현재가 추가행은 과거 이력에서 제외한다.

## 비교 결과

| 감사 범위 | 자체 집계·판단 |
|---|---|
| 8제품 주간 | 제품당 고유 주간 12행, 양 표면 총 96행 일치. 1개월과 3개월 중복을 합산하지 않음 |
| 전체 조회창 월간 | 표면간 값 불일치 13건, 모바일 단독 6건, PC 단독 0건 |
| 불일치 위치 | 전부 조회창의 가장 오래된 월. 경계월 집계 영향 가능성은 가설이며 원인 미확정 |
| PC 내부 기간 중첩 | 불일치 9건. 모바일 내부는 0건 |
| 주·월 연결 | 주간을 확보한 2026-08~10에 월값과 그 달 주간 최소가가 일치. 이전 달로 일반화하지 않음 |

불일치 값은 평균·덮어쓰기하지 않고 상태와 근거를 보존했다. 당월은 미완성 월이다. 희소 GPU의 높은 양수 호가도 오류 확정 없이 수정하지 않고 대표 시장 가격으로 쓰지 않는다. 최고 기간 24개월은 실제 일별 2년 데이터라는 뜻이 아니다. `totalCount`를 고유 행수로 쓰지 않는다.

## 실행과 제한

[감사 코드](../scripts/audit_domestic_prices.py)는 저장 입력만 읽고 원본 해시 불변·중복·일치 여부를 검사한다. 공개 저장소에는 필요한 다나와 원본이 없어 이 전체 감사를 실행할 수 없다. [제외 파일 목록·취득 조건](../data/README.md)을 먼저 확인한다. [원문 제품 예시](https://prod.danawa.com/info/?pcode=21694499), [모바일 예시](https://m2.danawa.com/product/product.html?code=21694499).
