# 3개월 가격 확률 모형 — 사전 고정 검증 규약

작성: 2026-10-23. 아래 규약은 새 모형의 점수를 확인하기 전에 고정한다.

## 예측 대상과 시장

- 상승: 3개월 뒤 같은 상품·가격 정의의 가격이 현재보다 **3% 초과 상승**. 하락: **3% 초과 하락**. 그 사이는 보합이다. 3%는 구매 판단의 정책 기준이며 최적화하지 않는다.
- 주별 자료: 관측 주의 금요일에서 **달력상 3개월 뒤 날짜 이상인 첫 금요일**의 가격. 실제 평가 간격은 13 또는 14주이며 목표 날짜를 저장한다. 목표 주가 없으면 제외한다. 앞뒤 주의 관측으로 대체하지 않는다.
- 월별 자료: 정확히 3개 달 뒤의 동일한 원문 버킷을 예측한다. 주별 모형과 합치지 않는다. 부분월은 학습·평가에서 제외한다. 마지막 완료 월에서 3개월 뒤이므로 오늘부터 3개월 예측으로 표시하지 않는다.
- 국가·통화·신품/리퍼 조건·가격 정의가 다른 계열은 이어 붙이지 않는다. 해외 확률을 국내 SKU 추천에 적용하지 않는다.

## 학습 및 모델 선택

- 입력은 과거 가격의 1/4/12/26주 변화, 12주 중앙값 대비 가격, 인접 주 변동성·범위·관측률·상품 관측기간이다. 월별은 1/2/3/6개월 변화와 최근 6개월 특징을 쓴다. 이후 가격·이후 주가·전체 기간의 이상치 판정은 입력하지 않는다.
- 누락된 특징은 해당 학습 집합의 중앙값으로만 대체하고 결측 표시자를 함께 입력한다. 원본 가격·목표 가격을 이월·보간하지 않는다.
- 원문 오류로 이미 격리했던 CPU $1.47은 USD 가격의 고정 $5 하한으로 제외한다. 미래 이웃 가격으로 이상치를 판단하지 않으며, 하한을 쓰지 않은 전체 파이프라인 결과도 별도로 보존한다. 하한은 다른 통화에 적용하지 않는다.
- 주별 모형은 동일 SKU 단위, 국내 월별 모형은 동일 가격 정의의 국내 패널로 학습한다. 패널 입력에 부품 종류를 포함하며 검증 시점별로 전체 제품의 미래 결과를 함께 차단한다.
- 후보: 표준화된 L2 다항 로지스틱 회귀(C=1)와 깊이 제한 랜덤포레스트(120그루, 깊이 3, 최소 잎 12, seed 20261023). 초모수 탐색은 하지 않는다.
- 분기별 재학습. 예측 분기 시작일 이전에 **목표 기간까지 종료한** 사례만 학습한다. 분기 중 미래에 성숙할 정답을 미리 학습하지 않는다. 주별 최소 학습 80개·각 클래스 5개, 월별 패널 최소 48개·각 클래스 5개·6개 학습 원점이 필요하다.
- 주별 선택 구간은 2023–2024년 원점 중 목표일이 2024-12-31 이내인 과거 예측이다. 후보별 raw/temperature(0.5,1,2,4) 중 로그손실 최소를 선택한다. 보정도 이 과거 구간만 사용한다. 선택이 불가능하면 고정 로지스틱·온도 1을 쓰고 미선택 상태를 표시한다.
- 최종 평가는 원점 2025-01-01 이후이며 정답이 수집 시점까지 성숙한 사례만 쓴다. 이후 결과로 후보·온도를 다시 고르지 않는다. 국내 월별은 사전 선택 구간이 부족하므로 고정 로지스틱·온도 1, 실험 상태다.

## 평가 및 공개 조건

- 3클래스 Brier(세 클래스 제곱오차 합), 로그손실, 정확도, 클래스별 보정 구간·빈도·Wilson 구간을 공개한다. Brier가 낮다는 것만으로 보정이 입증됐다고 하지 않는다.
- 기준 확률은 같은 학습 집합의 클래스 발생 빈도(Laplace +1). 가격 유지 및 직전 추세의 3개월 변화율 MAE도 따로 비교한다. 가격 오차와 확률 점수는 다른 평가다.
- 점 예측은 학습 집합에서 방향별 실제 변화율 중앙값을 구한 뒤 세 예측 확률로 가중한 값이다. 별도 회귀 모형이 아니다. 드리프트 기준은 직전 12주(월별은 3개월)의 로그 변화를 목표 간격에 맞게 연장한다. 해당 과거 특징이 없으면 드리프트는 0 변화로 둔다.
- 중첩 사례 수와 **목표 기간이 겹치지 않는 시간 구간 수**를 함께 공개한다. 제품 수를 독립적인 경기 사이클 수로 세지 않는다.
- 시간 원점별 평균 점수 차이에 3개월 블록 부트스트랩(seed 20261023, 1,000회)을 적용해 기준 대비 Brier 개선의 95% 구간을 구한다. 월별은 3개 원점, 주별은 14개 원점 블록. 결측으로 불규칙할 때도 달력 시간 블록으로 묶는다.
- 구매 추천 반영 조건: 최종 평가 **주별 52개 원점 또는 월별 12개 원점**, 비중첩 시간 구간 **8개 이상**, 세 클래스별 **10개 이상**, 기준 대비 Brier 개선 95% 구간 하한 > 0, 로그손실 개선, 보정의 가중 절대차 ≤ 0.10. 모두 통과해야 한다. 표본이 모자라거나 실패하면 확률은 실험 결과로만 표시하고 구매 추천에는 쓰지 않는다.
- 통과한 경우에만 상승 확률 ≥ 0.60이고 하락보다 0.20 이상 크면 앞당김, 반대면 대기를 검토한다. 데이터가 오래됐거나 판매처·견적 기준에 문제가 있으면 이 정책보다 재확인이 우선이다. 임계값은 검증 성능을 높이기 위해 최적화하지 않는다.
- 2025–2026년 최종 평가 범위의 길이 자체도 제한이다. 시간 구간 8개 기준을 충족할 충분한 기간이 없을 수 있다. 학습·선택에 사용한 예전 결과를 독립 최종 평가에 재사용해 이를 채우지 않는다.
- 현재 조회한 과거 스냅샷으로 한 회고 검증이다. 당시 수집본을 복원한 실시간 실험이 아니며, 자료의 사후 수정·누락 선택 편향은 남는다. 인과나 수익 보장을 주장하지 않는다.

## 2026-10-24 확장 비교 규약: ARIMA·SARIMA·ETS

위 내용은 최초 두 분류 모형의 규약이다. 아래는 새 비교 결과를 계산하기 전에 고정한 확장 규약이다. 기존 2025–2026년 결과를 이미 열람했으므로 이번 확장 비교는 **회고 벤치마크**이며 새 미관측 홀드아웃 검증이 아니다. 모델 선택에는 여전히 2023–2024년 자료만 쓴다. 새 모델이 구매 기준을 통과하도록 기존 문턱을 바꾸지 않는다.

| 후보 | 고정 사양 | 점 예측·확률 |
|---|---|---|
| 로지스틱·랜덤포레스트 | 위와 동일; 국내 두 후보 모두 동일 21 SKU 패널 | 방향별 학습 변화율 중앙값의 확률 가중합 |
| ARIMA | 로그가격 ARIMA(1,1,0), 드리프트 포함 | 로그가격 가우시안 예측 분포; 가격 중앙값 |
| SARIMA | 로그가격 (1,1,0)(1,0,0,s), 드리프트 없음; s=52주/12개월 | 동일; 고정 연간 주기 가설을 비교 |
| ETS | 로그가격 ETS(A,Ad,N): 가법 오차·감쇠 가법 추세·비계절 | 동일; 계절 ETS의 검증을 뜻하지 않음 |

- 차수·주기 탐색은 하지 않는다. 특히 주간 52주는 달력 연간 주기의 근사이며 불규칙 공급 충격을 매년 반복되는 계절성으로 간주하지 않는다. ETS 초기 수준은 적합 구간 첫 유효 로그가격, 초기 추세는 인접한 유효 로그차이의 중앙값이다.
- 시계열 후보의 최소 적합 구간은 주간 달력 52칸·실관측 40개, 월간 12칸·실관측 10개다. SARIMA는 추가로 달력 2주기와 마지막 두 주기 각각 75% 관측이 필요하다. 이는 이번 실험의 최소 규칙이며 두 주기만으로 계절성이 입증됐다는 뜻은 아니다. 국내 최대 22개월은 연간 SARIMA 대상에서 제외한다.
- 분기 시작일 **이전**에 이용 가능했던 가격으로 분기마다 한 번 최대우도 적합한다. 월간 가격은 해당 월의 익월 1일부터 이용 가능하다. 파라미터는 분기 중 고정하고, 각 원점까지의 가격만 `apply(refit=False)`로 필터링한다. 원점 이후 값은 입력하지 않는다. 분류 후보는 3개월 정답까지 성숙한 학습 사례만 쓰므로 가격 모형과 학습 표본의 의미가 다르다.
- 달력 결측을 NaN으로 유지한 상태공간 모형만 사용한다. 행 삭제로 시간을 압축하거나 가격·정답을 보간/이월하지 않는다. 내부 상태 예측을 실제 관측으로 세지 않는다. 최대 100회 최적화 후 미수렴이면 동일 자료·직전 파라미터로 200회 한 번 재시도한다. 여전히 미수렴·비유한 파라미터·비유한 예측은 제외하고 사유와 시도를 기록한다.
- `get_forecast`의 목표 시점 로그가격 예측 평균 μ와 **다단계 예측 분산** v를 사용한다. 잔차 표준편차만으로 확률을 만들지 않는다. 하락 확률=Φ((log(0.97×원점가격)−μ)/√v), 상승 확률=1−Φ((log(1.03×원점가격)−μ)/√v), 보합은 나머지다. 예측 분포는 추정된 파라미터에 조건부이며 파라미터 추정 불확실성 전체를 포함하지 않는다.
- 비교·온도 선택에 사용할 과거 표본은 2023–2024년 원점 중 정답이 2024년 말까지 이용 가능한 사례다. 해당 과거 기간에 24개 이상 예측을 낸 후보들의 **동일 원점 교집합**으로 후보·온도(0.5/1/2/4)를 함께 선택한다. 교집합 24개·세 방향 결과가 부족하면 기존 선택을 유지한다. 평가 점수가 낮다는 이유로 사후 교체하지 않는다. 동점은 기존 분류 후보→ARIMA→SARIMA→ETS 순, 이후 낮은 온도 순이다.
- 2025년 이후의 성숙한 평가 사례에서는 예측을 한 건 이상 산출한 후보들의 **동일 원점 교집합**에서 비교한다. 미산출 후보는 제외 상태와 사유를 표시한다. 각 후보의 전체 평가 가능 행 수(`allTestN`)와 공통 n을 나란히 기록해 표본 축소를 확인한다. 선택 교집합과 평가 교집합의 후보 목록은 다를 수 있으며 JSON에 각각 기록한다.
- 비교 범위는 기존 분류 모형이 산출한 평가 원점으로 고정한다. `allTestN`도 이 범위 안의 후보별 수다. 범위 밖의 시계열 단독 산출은 `standaloneTestN`에 수만 기록하고 비교·모형 교체 근거에 넣지 않는다. 공통 평가가 0이어도 시계열 단독 예측까지 불가능하다는 뜻은 아니다.
- 모형별 확률은 그 모형의 과거 선택 구간에서 고른 온도를 적용한다. 과거 선택이 불가능한 후보는 온도 1, 유지한 기존 후보는 원래 온도를 쓴다. 가격 모형의 점 예측 `exp(μ)/원점가격−1`과 80/95% 구간은 원분포에 기반하며 확률 온도로 바꾸지 않는다. 분류 모형의 점 예측과 산정법이 다르므로 확률 우열과 가격 오차 우열을 분리한다.
- Brier·로그손실·ECE·변화율 MAE/RMSE(%p), 비중첩 시간 구간 수, 원분포 80/95% 구간 포함률과 n을 공개한다. 평균 변화율 오차는 원화/달러 가격 오차가 아니다. 모형 간 쌍별 유의성 검정은 하지 않으며, 최저 시험 점수를 미래 우위나 구매 추천으로 해석하지 않는다.
- 선택된 모형은 전체 산출 가능 평가 사례와 최신 예측에 반영한다. **공통 표본의 비교 점수**와 **선택 모형의 전체 검증 점수**를 구분한다. 최신 분류 모형은 기존 동작대로 원점에서 이미 성숙한 정답으로 재학습하며, 최신 시계열 모형은 해당 분기의 고정 파라미터를 사용한다.
- 재현 순서: 기존 `build_forecast.py` 실행 후 `compare_forecast_models.py`. 이전 두 모형 결과는 최초 실행 시 `data/analysis/2026-10-24/model_comparison/legacy_forecast.json`에 보존한다. 후보별 원점 예측·적합 감사는 비공개 연구 경로에 저장한다. 공개판은 `data/public/model_comparison.json`의 집계 점수·선택·실패 사유만 제공한다.

구현 근거: [SARIMAX](https://www.statsmodels.org/stable/generated/statsmodels.tsa.statespace.sarimax.SARIMAX.html), [상태공간 지수평활](https://www.statsmodels.org/stable/generated/statsmodels.tsa.statespace.exponential_smoothing.ExponentialSmoothing.html), [결측 상태공간 예제](https://www.statsmodels.org/stable/examples/notebooks/generated/statespace_sarimax_internet.html).
