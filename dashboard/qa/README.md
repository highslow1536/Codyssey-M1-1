# 브라우저 검증 기록

2026-10-22, IAB 브라우저와 로컬 정적 서버에서 확인했다.

- 데스크톱 1280×720: CPU·SSD·GPU 전환, 가격 기준 변경, 연도 선택, 원 가격과 지수 비교가 동작했다.
- 실제 표본: CPU 148주·SSD 135주, GPU 3070 소매 33조사일/32주, eBay 16개월이었다. GPU 2020 선택 시 가격·그래프는 미관측으로 표시됐다.
- 월별 가격은 `2022-12 월평균`처럼 표시하며 특정 관측일을 만들지 않았다.
- 상관 지도·시차: CPU–AMD L=0은 r=−0.046, n=140. L=+7 선택 시 r=+0.249, n=137로 바뀌고 산점도도 함께 갱신됐다.
- 채굴 화면: GPU 3종의 전후 비교는 각 2개월/2개월이다. RTX 3070 수수료 제외 대용 B의 변화율 상관은 소매 n=32, eBay n=11로 구분됐다.
- 품질 화면: 결측·혼합 주·PoW 종료, Beacon/London 편향, 204회 다중 비교 한계와 다운로드 링크가 표시됐다.
- 390px iframe: 가격·상관 화면의 `body.clientWidth`와 `scrollWidth`는 모두 390이었다. 차트 축·날짜는 모바일 폭에 맞게 다시 그렸고 상관 표만 내부 가로 스크롤을 사용한다. 임시 iframe 페이지는 배포 산출물에서 제거했다.
- SVG 경로에서 NaN/Infinity 좌표는 없었다. 브라우저 로그에는 앱 소스에 없는 MutationObserver 오류 1건이 있었으며 발생 출처는 확인되지 않았다. 관찰한 화면 동작에는 영향을 주지 않았다.
- Python 전체 테스트 **65개**, Node 모델 테스트 **8개**, JS 구문 검사 통과. 산점도·시차의 실제 n/r, 원본 데이터·다운로드 해시, 결측 경계를 대조했다.

`desktop.png`는 최종 가격 추이 화면, `mobile.png`는 390px 모바일 차트 검증 화면이다. 둘 다 실제 브라우저 캡처다.
